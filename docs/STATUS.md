# 项目状态与开发交接

更新：2026-10-26

版本：`0.1.0`  
阶段：Phase 6.5（受邀试用与人工验收），不是 7×24 正式运营版本

## 1. 一句话结论

这是一个**功能完整、自动门禁通过、但尚未完成教学质量和真实设备验收**的考研英语学习工具。代码可以开源和部署；不能把自动测试通过等同于教师评分准确、OCR 准确或长期稳定运行。

## 4. 已知限制与风险

### 产品范围

- 无登录、无支付、无服务端数据库、无多租户。
- 历史只存在浏览器；换设备、换域名或清缓存不会自动迁移。
- 无账号意味着公网地址一旦泄露，任何人都能消耗模型额度。必须用 Cloudflare Access、反向代理认证或内网限制。
- 真题数据不随代码许可证授权，公开仓库默认不带题库。

### 质量与验收

- AI 分数只是练习参考，不是教师评分。
- 教师盲评、真实学生手写、真实手机、原生打印/另存 PDF、真实备用供应商切换尚未完成签核。
- 模型结构化输出偶发失败；已有 JSON 修复、流式预览与未完成反馈兜底，但不能承诺 100% 格式稳定。
- 独立 Eval 曾出现文本降级和同模型评审不确定项，历史失败仍保留。

### 运行可靠性

- 维护者本机的 Windows 计划任务监护曾多次出现 `0xC000013A` 异常退出，来源未定位；应用进程在部分情况下仍可服务。
- 任何“恢复后健康”的短时证据都不等于长期稳定。
- 前版Docker镜像与app+Caddy全栈已实测。本次速度优化尚未重新构建容器镜像；远程CI/目标服务器验证仍待完成。
- 依赖审计以最新一次 `pnpm audit --prod` 为准，不能沿用历史 0 告警。

## 5. 下一步优先级

### P0：公开发布前

1. 使用 `pnpm release:source` 生成干净发行包，不直接公开当前 Git 历史。
2. 在全新目录跑通 `install → lint → typecheck → test → build`。
3. 用 Docker 构建镜像并以空题库启动，执行 `verify-deploy --readonly --allow-empty-bank --allow-no-ocr`。
4. 若公开在线 Demo，配置访问控制、额度告警和独立 API Key。

### P1：安全与运维

1. 为公网实例配置 Cloudflare Access 或等效认证。
2. 在反向代理层覆盖 `X-Real-IP` / `X-Forwarded-For`，防止伪造 IP 绕过内存限流。
3. 增加进程级监控、日志轮转与密钥轮换说明。
4. 对公开实例设置模型日预算和供应商侧限额。

### P2：质量验收

1. 真实手机完成“作文 → 追问 → 历史导出”。
2. 教师对 3–5 篇作文独立盲评，与 AI 分数对照。
3. 真实学生手写图片核对错字率。
4. 原生打印/另存 PDF 检查分页和完整性。
5. 配置真实备用供应商并验证切换。
6. 阅读题库人工抽查。

### P3：后续功能

- 模板库 / RAG 仍是规划，不因本次开源准备而启用。
- Harness、Pi、Jev、RSI 仅为研究提案，未接入代码。

2. 不删除或覆盖历史失败记录。
