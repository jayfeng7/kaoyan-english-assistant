# 使用说明

## 1. 开始之前

- 打开部署地址即可使用，不需要注册或登录。
- 所有历史记录保存在**当前浏览器**。换手机、换浏览器、换域名或无痕窗口不会自动同步。
- AI 批改依赖部署者配置的模型 Key；图片识别还依赖百度 OCR。
- 分数是练习参考，不是教师评分。

## 2. 作文批改

### 题目来源

- **历年真题**：按考试类型、作文类型和年份载入题目。
- **其他题目**：手动输入题目，或上传题目图片/PDF 识别。

公开源代码版本默认不包含题库；此时使用“其他题目”。

### 正文输入

- 直接粘贴英文正文；
- 或上传手写图片 / PDF。

限制：

| 类型 | 限制 |
|---|---|
| 图片 | JPG / PNG / WebP，原图 ≤ 10MB |
| PDF | ≤ 20MB，≤ 5 页，每次处理一篇 |
| 题目文字 | ≤ 500 字符 |
| 正文 | ≤ 8000 字符 |

扫描 PDF 会在浏览器本机逐页渲染，只上传页面图片；文字 PDF 会上传到服务器提取文字。OCR 结果可以直接编辑。**不要自动纠正学生原文中的语法和拼写错误**，只需修正识别错字。

### 结果

完整结果包含：

新批改先完成评分、总评、关键批注和两条建议，随后即可追问。需要改进版或范文时展开“改进版与参考”，内容生成后会一起保存；不会再次改变分数。旧历史中的完整报告仍可直接查看。

- 得分与满分（英一 20 / 英二 15 / 小作文 10）；
- 档次与定档理由；
- 内容、语言、结构分项；
- 总评、优先修改建议；
- 逐句批注、改进版、范文、可积累表达。

如果模型输出未通过结构校验，页面会保留已生成的文字反馈，但**不会显示有效分数**。此时可以继续讨论，或重新批改。

### 追问

完整报告或未完成反馈下方可以继续提问。追问会携带当前作文的题目、原文和已有反馈；回答以流式显示。生成中可以停止；停止后保留已有文字和草稿。

### 打印

完整报告支持浏览器打印/另存 PDF。打印视图包含题目、原文和完整报告，不包含输入控件、追问和导航。

尚未展开生成的参考内容会在打印中注明“尚未生成”。如需包含范文，先展开参考区并等待完成，再打印。

## 3. 长难句

输入一个英文句子，得到：

1. 意群断句；
2. 主干；
3. 从句；
4. 修饰成分；
5. 中文翻译；
6. 语法点；
7. 仿写。

## 4. 真题解析

三种入口：

- 题库选择；
- 粘贴文章与题目；
- 上传文字 PDF。

可先作答，再生成段落精读、题目定位、干扰项分析。全文翻译默认不生成，需要时再请求。

没有本地题库时，使用粘贴或 PDF。

## 5. 学习答疑

支持多轮上下文和流式输出。可以停止回答，失败后重试同一问题不会重复保存一组问答。

## 6. 历史记录

历史页支持：

- 按类型筛选；
- 全文搜索；
- 打开并恢复题目、原文、结果和追问；
- 删除单条、按类型删除或全部清空；
- 导出全部 JSON；
- 导入 JSON，按记录 ID 合并。

### 备份建议

1. 进入“历史记录”；
2. 点击导出；
3. 将 JSON 保存到网盘或本地；
4. 清除浏览器数据、换设备或换域名前先导出。

导出文件包含作文原文、批改结果和聊天内容，请按个人隐私材料保管。

## 7. 设置

可以设置默认考试类型、默认大小作文、全文翻译默认展开和阅读字号。设置同样保存在当前浏览器。

## 8. 常见问题

| 现象 | 处理 |
|---|---|
| 页面提示缺少题库 | 使用自由题目、粘贴文章或 PDF；或由部署者导入已授权题库 |
| 提示服务不可用 | 检查服务端模型 Key、余额和网络；稍后重试 |
| 图片识别失败 | 检查百度 OCR 是否配置；可改用文字输入 |
| PDF 解析失败 | PDF 可能加密、损坏或没有文字层；改用扫描模式或粘贴文字 |
| 历史不见 | 是否换了浏览器/域名、用了无痕模式，或清除了站点数据？尝试导入备份 |
| 分数未显示 | 模型结果未通过结构校验；可重试或继续讨论已有文字反馈 |
| 请求过于频繁 | 触发了单 IP 限流，等待提示时间后重试 |

## 9. 隐私提示

- 服务端不保存你的历史记录，但调用模型/OCR 时必要内容会发送给对应供应商。
- 不要在公开 Issue、截图或聊天中粘贴 API Key、隧道 Token、真实学生作文或教师盲评材料。
- 公开部署地址建议由部署者加访问控制；否则任何拿到地址的人都能使用模型额度。
